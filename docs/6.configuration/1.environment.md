# Configuration

## Environment Variables

| Variable                                   | Default                 | Description                                                     |
| ------------------------------------------ | ----------------------- | --------------------------------------------------------------- |
| `VUESTRATA_APP_TITLE`                      | `Vuestrata`             | Human-facing application title exposed as `VUESTRATA_APP_TITLE` |
| `VUESTRATA_APP_URL`                        | `http://localhost:3333` | Public application URL (used in previews, redirects)            |
| `VUESTRATA_AUTH_ADAPTER`                   | `mock`                  | Auth adapter: `mock`, `jwt`, `oauth`                            |
| `VUESTRATA_USE_MOCKS`                      | `true`                  | Enable MSW mock handlers in development                         |
| `VUESTRATA_API_URL`                        | —                       | Backend API base URL                                            |
| `VUESTRATA_UI_PROVIDER`                    | `reka`                  | UI provider: `reka`, `vuetify0`                                 |
| `VUESTRATA_ICON_PROVIDER`                  | `solar`                 | Icon provider: `solar`, `lucide`, `phosphor`                    |
| `VUESTRATA_VALIDATION_ADAPTER`             | `zod`                   | Validation adapter: `zod`, `valibot`, `yup`, `arktype`          |
| `VITE_VUESTRATA_DEMO_AUTH_RETENTION_HOURS` | `24`                    | How long (hours, min 1) demo sessions are retained in IndexedDB |

## App Configuration

Centralized configuration is in `src/modules/app/config/app.config.ts`.

An approximate shape of `appConfig` exposed by the module is:

```ts
export const appConfig = {
  title: import.meta.env.VUESTRATA_APP_TITLE || 'Vuestrata',
  apiUrl: import.meta.env.VUESTRATA_API_URL || '/api',
  useMocks: import.meta.env.VUESTRATA_USE_MOCKS === 'true',
  authProvider: import.meta.env.VUESTRATA_AUTH_ADAPTER || 'mock',
  uiProvider: import.meta.env.VUESTRATA_UI_PROVIDER || 'reka',
  iconProvider: import.meta.env.VUESTRATA_ICON_PROVIDER || 'solar',
  validationAdapter: import.meta.env.VUESTRATA_VALIDATION_ADAPTER || 'zod',
  demoAuth: {
    retentionHours: Number(import.meta.env.VITE_VUESTRATA_DEMO_AUTH_RETENTION_HOURS) || 24,
  },
}
```

## MSW Mock Handlers

In development, [MSW](https://mswjs.io/) intercepts HTTP requests and returns mock data. Mock handlers cover:

- Auth (login, register, refresh, social, magic link)
- Dashboard (stats, activity, revenue, team)
- Users (paginated, searchable, role editing)
- Billing (subscription, invoices, payment methods)
- Audit logs (paginated, filterable)
- Module-aware handlers registered by the active app modules

Enable mocks with:

```bash
VUESTRATA_USE_MOCKS=true
```

## Docker

A `Dockerfile` and `docker-compose.yml` are provided for containerized deployment:

```bash
docker compose up --build
```

## Deployment

The production build outputs to `dist/`:

```bash
vp build
```

Static hosting headers for Cloudflare Pages are pre-configured in `public/_headers`.
