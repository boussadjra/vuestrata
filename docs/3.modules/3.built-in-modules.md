# Built-in Modules

This page documents the active module set shipped with Vuestrata.

## Auth

| Property      | Value                                           |
| ------------- | ----------------------------------------------- |
| ID            | `auth`                                          |
| Category      | `core`                                          |
| Default       | Enabled                                         |
| Required      | Yes (cannot be disabled)                        |
| State pattern | Pinia (auth store, infrastructure) + composable |

Auth owns the public authentication surface: `/auth/login`, `/auth/register`,
`/auth/callback` pages, the `useAuth` composable, PKCE helpers, and the MSW
mock handlers used by the `mock` adapter. The auth Pinia store, API
auth-interceptor, router guard, and RBAC engine remain in
`src/modules/app/` and `src/modules/core/` because they boot before the
module system.

The module is registered first in `setup.ts` and its `mockHandlers()` hook
contributes the auth handlers that MSW starts after `setupModules` runs.

Public API:

- `useAuth`
- `createAuthAdapter`, `resolveAuthAdapterName`
- `exchangeOAuthCode`, `OAuthRedirectError`
- `generateCodeVerifier`, `generateCodeChallenge`, `generateState`
- `AuthAdapter` (type)
