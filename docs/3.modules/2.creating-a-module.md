# Creating a Module

Use this flow to add a new module under `src/modules/`.

## 1. Create Module Folder

```bash
mkdir -p src/modules/reports/{composables,stores,i18n,__tests__}
```

## 2. Define Module Types (Optional)

```ts
// src/modules/reports/types.ts
export interface ReportsFilters {
  period?: 'day' | 'week' | 'month'
  page?: number
  pageSize?: number
}
```

## 3. Add Query Keys

```ts
// src/modules/reports/query-keys.ts
import { defineQueryKeys } from '~/lib/query-keys'

export const reportsKeys = {
  ...defineQueryKeys('reports'),
  summary: () => ['reports', 'summary'] as const,
}
```

## 4. Pick a State Pattern

For server data, use TanStack Query composables:

```ts
// src/modules/reports/composables/useReports.ts
import { useQuery } from '@tanstack/vue-query'

import { apiGet } from '~/lib/api/client'

import { reportsKeys } from '../query-keys'

export function useReports() {
  return useQuery({
    queryKey: reportsKeys.summary(),
    queryFn: () => apiGet('/reports/summary'),
  })
}
```

For local preferences only, use Pinia + `useAppStorage` in a store.

## 5. Define Module Entry

```ts
// src/modules/reports/index.ts
import type { ModuleDefinition } from '~/modules/types'

const reportsModule: ModuleDefinition = {
  config: {
    id: 'reports',
    name: 'Reports',
    description: 'Reporting tools',
    version: '1.0.0',
    category: 'analytics',
    enabledByDefault: true,
    // Optional: `required: true` prevents the module from being disabled at
    // runtime via the module store. Use only for foundational modules like
    // `auth` whose absence would break other modules.
  },
  navItems: [
    {
      label: 'reports_nav',
      icon: 'chart',
      to: '/dashboard/reports',
      order: 60,
    },
  ],
  i18n: {
    en: { reports_nav: 'Reports' },
  },
}

export default reportsModule
```

## 6. Register the Module

Add it in `src/modules/setup.ts`:

```ts
import reportsModule from './reports'

export const appModules = [billingModule, usersModule, settingsModule, reportsModule]
```

## 7. Add Tests

Create module-level tests under `src/modules/reports/__tests__/`.

## Checklist

- Module folder created under `src/modules/<name>/`
- `index.ts` exports a valid `ModuleDefinition`
- Query/store ownership follows state boundary rules
- Public API exported from module barrel only
- Module added to `src/modules/setup.ts`
- i18n entries added
- Tests added for module contract
