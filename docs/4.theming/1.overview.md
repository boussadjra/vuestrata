# Theming

Vuestrata ships with 10 built-in themes, persistent dark mode, and a separate shape system for radius, border, and shadow controls. Theme registry data lives in `src/modules/app/config/theme.config.ts`, base tokens live in `src/modules/app/styles/app.css`, and user-facing controls are exposed through `useTheme()` and `useShape()`.

## Built-in Themes

| Theme       | Style               | Key Colors                          |
| ----------- | ------------------- | ----------------------------------- |
| `default`   | Clean, professional | Blue primary, neutral surfaces      |
| `blueprint` | Technical, precise  | Blueprint blue, structured grids    |
| `brutalist` | Bold, high contrast | Stark blacks, thick borders         |
| `febin`     | Modern, vibrant     | Vibrant primary, clean surfaces     |
| `forest`    | Natural, earthy     | Deep greens, wood tones             |
| `ghibli`    | Soft, whimsical     | Warm earth tones, rounded shapes    |
| `ocean`     | Cool, aquatic       | Deep blues, teal accents            |
| `rose`      | Elegant, soft       | Rose pinks, gentle surfaces         |
| `sunset`    | Warm, vibrant       | Orange-red gradients, warm surfaces |
| `terminal`  | Hacker, monospace   | Green on black, mono fonts          |

## Using Themes

```ts
import { useTheme } from '~/composables/useTheme'

const { currentTheme, currentThemeName, themes, isDark, setTheme, toggleDark, registerTheme } =
  useTheme()

// List all available themes
console.log(themes.value.map((theme) => theme.name))

// Switch theme
setTheme('ocean')

// Toggle dark mode
toggleDark()
```

## How Themes Work

Themes use CSS custom properties defined in `src/modules/app/styles/app.css` and the imported theme CSS files:

1. `bootstrapTheme()` applies the persisted theme, dark-mode, and locale snapshot before Vue mounts.
2. `useThemeSync()` keeps `<html>` in sync after mount using the shared `applyAppearance()` helper.
3. `src/modules/app/config/theme.config.ts` maps a theme name to the CSS class applied on `<html>`.
4. `src/modules/app/styles/app.css` imports the built-in theme files and defines the base token set.

::alert{type="warning"}
Tailwind CSS v4 requires `@custom-variant dark (&:where(.dark, .dark *));` in the CSS for class-based dark mode. Without this, `dark:` utilities target the `prefers-color-scheme` media query.
::

## Theme Tokens

Each theme can override these CSS custom property groups:

```css
/* Primary palette */
--color-primary-50 through --color-primary-950

/* Accent palette */
--color-accent-50 through --color-accent-950

/* Surface palette */
--color-surface-50 through --color-surface-950

/* Typography */
--font-sans, --font-mono

/* Shapes */
--radius-sm, --radius-md, --radius-lg, --radius-xl
```

## Creating a Custom Theme

### 1. Define CSS Variables

```css
/* src/modules/app/styles/themes/midnight.css */
:root.theme-midnight {
  --color-primary-500: #6366f1;
  --color-primary-600: #4f46e5;
  --color-accent-500: #f59e0b;
  --color-surface-50: #0f172a;
  --color-surface-900: #f8fafc;
  --font-sans: 'Inter', sans-serif;
}
```

### 2. Register the Theme

```ts
import { registerTheme } from '~/config/theme.config'

registerTheme({
  name: 'midnight',
  label: 'Midnight',
  cssClass: 'theme-midnight',
})
```

Import the CSS file from `src/modules/app/styles/app.css` so the class is available at runtime.

### 3. Use the Theme

```ts
const { setTheme } = useTheme()
setTheme('midnight')
```

## Shape System

Shape controls are managed separately from themes via `useShape()`:

```ts
import { useShape } from '~/composables/useShape'

const { radius, border, shadow, setRadius, setBorder, setShadow } = useShape()

setRadius('large')
setBorder('bold')
setShadow('elevated')
```

Available values:

- `radius`: `none`, `small`, `medium`, `large`
- `border`: `none`, `thin`, `medium`, `bold`
- `shadow`: `none`, `subtle`, `medium`, `elevated`

## Component-Level Theming

Components automatically pick up theme tokens through Tailwind CSS utility classes:

```vue
<template>
  <div class="bg-primary-500 text-white rounded-lg">Themed with current theme's primary color</div>
</template>
```

Dark mode variants apply automatically:

```vue
<template>
  <div class="bg-white dark:bg-surface-800 text-surface-900 dark:text-surface-100">
    Adapts to light/dark mode
  </div>
</template>
```
