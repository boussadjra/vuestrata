# Theming

Vuestrata ships with 10 built-in themes and full dark mode support. Themes are defined as CSS custom properties and managed via the `useTheme()` composable.

## Built-in Themes

| Theme       | Style               | Key Colors                          |
| ----------- | ------------------- | ----------------------------------- |
| `default`   | Clean, professional | Blue primary, neutral surfaces      |
| `blueprint` | Technical, precise  | Blueprint blue, structured grids    |
| `brutalist` | Bold, high contrast | Stark blacks, thick borders         |
| `febin`     | Modern, vibrant     | Vibrant primary, clean surfaces     |
| `forest`    | Natural, earthy     | Deep greens, wood tones             |
| `ghibli`    | Soft, whimsical     | Warm earth tones, rounded shapes    |
| `ocean`     | Cool, aquatic       | Deep blues, teal accents            |
| `rose`      | Elegant, soft       | Rose pinks, gentle surfaces         |
| `sunset`    | Warm, vibrant       | Orange-red gradients, warm surfaces |
| `terminal`  | Hacker, monospace   | Green on black, mono fonts          |

## Using Themes

```ts
import { useTheme } from '~/composables/useTheme'

const { theme, setTheme, isDark, toggleDark, themes } = useTheme()

// List all available themes
console.log(themes.value) // ['default', 'brutalist', 'ghibli', ...]

// Switch theme
setTheme('ocean')

// Toggle dark mode
toggleDark()
```

## How Themes Work

Themes use CSS custom properties defined in `src/styles/app.css`:

1. A base `@theme` block defines the default design tokens
2. Theme classes (`.theme-brutalist`, `.theme-ocean`, etc.) override tokens via CSS specificity
3. `.dark` class triggers dark mode via Tailwind's `dark:` variant
4. `useTheme()` manages state and applies classes to `<html>`

::alert{type="warning"}
Tailwind CSS v4 requires `@custom-variant dark (&:where(.dark, .dark *));` in the CSS for class-based dark mode. Without this, `dark:` utilities target the `prefers-color-scheme` media query.
::

## Theme Tokens

Each theme can override these CSS custom property groups:

```css
/* Primary palette */
--color-primary-50 through --color-primary-950

/* Accent palette */
--color-accent-50 through --color-accent-950

/* Surface palette */
--color-surface-50 through --color-surface-950

/* Typography */
--font-sans, --font-mono

/* Shapes */
--radius-sm, --radius-md, --radius-lg, --radius-xl
```

## Creating a Custom Theme

### 1. Define CSS Variables

```css
/* src/styles/app.css */
:global(html.theme-midnight) {
  --color-primary-500: #6366f1;
  --color-primary-600: #4f46e5;
  --color-accent-500: #f59e0b;
  --color-surface-50: #0f172a;
  --color-surface-900: #f8fafc;
  --font-sans: 'Inter', sans-serif;
}
```

### 2. Register the Theme

```ts
import { registerTheme } from '~/config/theme.config'

registerTheme({
  name: 'midnight',
  label: 'Midnight',
  description: 'Deep indigo theme',
})
```

### 3. Use the Theme

```ts
const { setTheme } = useTheme()
setTheme('midnight')
```

## Shape System

Themes include a shape system that controls border-radius globally:

```ts
import { useTheme } from '~/composables/useTheme'

const { shape, setShape } = useTheme()

// Available shapes: 'sharp' | 'rounded' | 'pill'
setShape('pill')
```

## Component-Level Theming

Components automatically pick up theme tokens through Tailwind CSS utility classes:

```vue
<template>
  <div class="bg-primary-500 text-white rounded-lg">Themed with current theme's primary color</div>
</template>
```

Dark mode variants apply automatically:

```vue
<template>
  <div class="bg-white dark:bg-surface-800 text-surface-900 dark:text-surface-100">
    Adapts to light/dark mode
  </div>
</template>
```
