# Testing

## Unit Tests

Unit tests use [Vitest](https://vitest.dev/) and are located in the `test/` directory.

```bash
# Watch mode
vp test

# Single run
vp test --run

# With coverage
vp test --coverage
```

### Test Coverage

| Area           | File                       | Tests                                         |
| -------------- | -------------------------- | --------------------------------------------- |
| RBAC Engine    | `test/rbac.test.ts`        | Role hierarchy, permissions, checking helpers |
| Error Handling | `test/errors.test.ts`      | AppError, normalizeError, error codes         |
| Stores         | `test/stores.test.ts`      | Auth, app, notification, billing stores       |
| Composables    | `test/composables.test.ts` | useTheme, useAuth, useRbac                    |

### Writing Tests

```ts
import { describe, it, expect, beforeEach } from 'vitest'
import { setActivePinia, createPinia } from 'pinia'

describe('My Feature', () => {
  beforeEach(() => {
    setActivePinia(createPinia())
  })

  it('should work correctly', () => {
    // Test implementation
    expect(result).toBe(expected)
  })
})
```

### Runtime State Reset

Tests that exercise the auth store, RBAC engine, or the demo persistence layer must call `resetRuntimeState()` instead of creating fresh Pinia instances manually. `resetRuntimeState()` is wired into `test/setup.ts` and runs automatically before every test, so you only need to call it explicitly when testing reset behavior itself.

```ts
import { resetRuntimeState } from '@test/utils/reset-runtime-state'

beforeEach(async () => {
  await resetRuntimeState()
})
```

When testing code that reads from the demo IndexedDB backend, call `clearAllDemoData()` (imported from `~/state/demo-store`) in your `afterEach` to leave the database clean for the next test. `fake-indexeddb` must be installed as a dev dependency and imported before the modules under test in those test files.

### E2E Tests

End-to-end tests use [Playwright](https://playwright.dev/) and are in the `e2e/` directory.

```bash
# Run e2e tests
vp run test:e2e

# Run with UI
vp run test:e2e:ui
```

### Configuration

Playwright is configured in `playwright.config.ts` with:

- Chromium, Firefox, and WebKit browsers
- Dev server auto-start
- Screenshot on failure
