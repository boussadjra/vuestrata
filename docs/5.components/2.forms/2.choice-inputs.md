# Choice Inputs

Choice inputs handle boolean toggles and one-of-many selections. Labels render **inline** next to checkboxes and switches (not above like text inputs).

::component-showcase{name="choice-inputs"}
::

---

## UiCheckbox

Single boolean toggle with three states: checked, unchecked, and indeterminate.

```html
<!-- Basic agreement checkbox -->
<UiCheckbox name="agree" label="I agree to the terms and conditions" required />

<!-- Indeterminate state (for "select all" patterns) -->
<UiCheckbox
  name="selectAll"
  label="Select all items"
  :indeterminate="someSelected && !allSelected"
  :model-value="allSelected"
/>

<!-- Size variants -->
<UiCheckbox name="small" label="Small checkbox" size="sm" />
<UiCheckbox name="medium" label="Medium checkbox" size="md" />
<UiCheckbox name="large" label="Large checkbox" size="lg" />
```

### Props

| Prop                                   | Type                         | Default | Description                                |
| -------------------------------------- | ---------------------------- | ------- | ------------------------------------------ |
| `modelValue`                           | `boolean \| 'indeterminate'` | `false` | Current state                              |
| `trueValue`                            | `boolean`                    | `true`  | Value emitted when checked                 |
| `falseValue`                           | `boolean`                    | `false` | Value emitted when unchecked               |
| `indeterminate`                        | `boolean`                    | `false` | Renders the `−` icon for partial selection |
| `size`                                 | `'sm' \| 'md' \| 'lg'`       | `'md'`  | Control size                               |
| + all `BaseFieldProps` (except `size`) |                              |         |                                            |

**Label rendering:** Inline next to the checkbox. Clicking the label toggles the checkbox.

**Formwerk composable:** `useCheckbox` — `role="checkbox"`, toggle on click/Space, tri-state `aria-checked`.

## UiSwitch

Styled on/off toggle with a sliding thumb animation.

```html
<!-- Basic switch -->
<UiSwitch name="notifications" label="Email notifications" />

<!-- Switches in a settings panel -->
<UiSwitch name="darkMode" label="Dark mode" size="sm" />
<UiSwitch name="autoSave" label="Auto-save" size="md" />
<UiSwitch name="publicProfile" label="Public profile" size="lg" disabled />
```

### Props

| Prop                                   | Type                   | Default | Description          |
| -------------------------------------- | ---------------------- | ------- | -------------------- |
| `modelValue`                           | `boolean`              | `false` | Current on/off state |
| `size`                                 | `'sm' \| 'md' \| 'lg'` | `'md'`  | Track and thumb size |
| + all `BaseFieldProps` (except `size`) |                        |         |                      |

**Label rendering:** Inline next to the switch track.

**Formwerk composable:** `useSwitch` — `role="switch"`, `aria-checked`, keyboard toggle.

## UiToggle

Button-style toggle (pressed/unpressed). The control is a rectangular button that fills with color when active.

```html
<UiToggle name="featured" label="Featured" size="md" />
<UiToggle name="pinned" label="Pin to top" size="sm" />
```

### Props

| Prop                                   | Type                   | Default | Description   |
| -------------------------------------- | ---------------------- | ------- | ------------- |
| `modelValue`                           | `boolean`              | `false` | Pressed state |
| `size`                                 | `'sm' \| 'md' \| 'lg'` | `'md'`  | Button size   |
| + all `BaseFieldProps` (except `size`) |                        |         |               |

**Label rendering:** The label text appears **inside** the toggle button itself. Supports a default slot for custom content (icons, etc.).

::alert{type="info"}
UiToggle does **not** render error or hint text. Use it for simple binary settings, not validated form fields.
::

**Formwerk composable:** `useCheckbox` (reused — a toggle is semantically a checkbox with button appearance).

## UiRadioGroup

One-of-many selection rendered as card-style radio buttons with optional per-option descriptions.

```html
<!-- Basic radio group -->
<UiRadioGroup
  name="plan"
  label="Subscription plan"
  :options="[
    { label: 'Starter — free',   value: 'starter' },
    { label: 'Pro — $9/month',   value: 'pro',  description: 'Priority support included' },
    { label: 'Team — $29/month', value: 'team', description: 'Up to 10 members' },
  ]"
  hint="You can upgrade at any time"
  required
/>

<!-- Horizontal layout -->
<UiRadioGroup
  name="priority"
  label="Priority"
  orientation="horizontal"
  :options="[
    { label: 'Low',    value: 'low' },
    { label: 'Medium', value: 'medium' },
    { label: 'High',   value: 'high' },
  ]"
/>
```

### Props

| Prop                   | Type                         | Default      | Description                     |
| ---------------------- | ---------------------------- | ------------ | ------------------------------- |
| `modelValue`           | `string`                     | —            | Currently selected option value |
| `options`              | `RadioOption[]`              | `[]`         | Array of options                |
| `orientation`          | `'vertical' \| 'horizontal'` | `'vertical'` | Layout direction                |
| `hint`                 | `string`                     | —            | Helper text below the group     |
| + all `BaseFieldProps` |                              |              |                                 |

### `RadioOption` type

| Field         | Type       | Description                                 |
| ------------- | ---------- | ------------------------------------------- |
| `label`       | `string`   | Display text                                |
| `value`       | `string`   | Form value                                  |
| `disabled`    | `boolean?` | Disables this specific option               |
| `description` | `string?`  | Secondary text shown below the option label |

**Formwerk composable:** `useRadioGroup` + `useRadio` — `role="radiogroup"`, arrow key navigation, `aria-checked`.

## UiToggleGroup

Button-group selection — segmented control style. Supports single and multiple selection modes.

```html
<!-- Single selection (radio-like) -->
<UiToggleGroup
  name="view"
  label="Layout"
  :options="[
    { label: 'Grid',  value: 'grid' },
    { label: 'List',  value: 'list' },
    { label: 'Table', value: 'table' },
  ]"
/>

<!-- Multiple selection -->
<UiToggleGroup
  name="features"
  label="Features"
  :multiple="true"
  :options="[
    { label: 'WiFi',    value: 'wifi' },
    { label: 'Parking', value: 'parking' },
    { label: 'Pool',    value: 'pool' },
  ]"
  size="sm"
/>
```

### Props

| Prop                                   | Type                   | Default | Description                                            |
| -------------------------------------- | ---------------------- | ------- | ------------------------------------------------------ |
| `modelValue`                           | `string \| string[]`   | —       | Selected value(s)                                      |
| `options`                              | `ToggleGroupOption[]`  | `[]`    | `{ label: string; value: string; disabled?: boolean }` |
| `multiple`                             | `boolean`              | `false` | Allow multiple simultaneous selections                 |
| `size`                                 | `'sm' \| 'md' \| 'lg'` | `'md'`  | Button size                                            |
| + all `BaseFieldProps` (except `size`) |                        |         |                                                        |

Buttons are visually connected with shared borders. Selected buttons fill with the primary color. Renders `role="group"` with `aria-pressed` on each button.
