# Selection Inputs

Selection inputs handle dropdowns, searchable lists, tags, hierarchical trees, file uploads, and one-time codes.

::

---

## UiSelect

Dropdown select with keyboard navigation, grouped options, and accessible popup.

```html
<!-- Basic select -->
<UiSelect
  name="country"
  label="Country"
  placeholder="Choose a country…"
  :options="[
    { label: 'United States', value: 'US' },
    { label: 'Canada',        value: 'CA' },
    { label: 'United Kingdom', value: 'GB' },
  ]"
  hint="Select your country of residence"
  required
/>

<!-- Multiple selection -->
<UiSelect
  name="languages"
  label="Languages spoken"
  placeholder="Select languages…"
  :options="languageOptions"
  :multiple="true"
/>
```

### Props

| Prop                   | Type                                    | Default     | Description                          |
| ---------------------- | --------------------------------------- | ----------- | ------------------------------------ |
| `modelValue`           | `string \| string[]`                    | —           | Selected value(s)                    |
| `options`              | `(SelectOption \| SelectOptionGroup)[]` | `[]`        | Flat or grouped options              |
| `placeholder`          | `string`                                | `'Select…'` | Text shown when no value is selected |
| `multiple`             | `boolean`                               | `false`     | Allow multiple selections            |
| `hint`                 | `string`                                | —           | Helper text                          |
| + all `BaseFieldProps` |                                         |             |                                      |

**Formwerk composable:** `useSelect` — popup toggle, keyboard navigation (arrow keys, Escape, Enter), `role="combobox"` + `role="listbox"`.

## UiComboBox

Searchable dropdown that filters options as the user types. The type `autocomplete` maps to the same component.

```html
<!-- Basic combobox -->
<UiComboBox
  name="timezone"
  label="Timezone"
  placeholder="Search timezones…"
  :options="[
    { label: 'UTC',            value: 'UTC' },
    { label: 'US/Eastern',     value: 'US/Eastern' },
    { label: 'US/Pacific',     value: 'US/Pacific' },
    { label: 'Europe/London',  value: 'Europe/London' },
    { label: 'Europe/Paris',   value: 'Europe/Paris' },
    { label: 'Asia/Tokyo',     value: 'Asia/Tokyo' },
  ]"
  hint="Start typing to filter"
/>

<!-- Open suggestions on focus -->
<UiComboBox
  name="assignee"
  label="Assign to"
  placeholder="Search team members…"
  :options="teamMembers"
  :open-on-focus="true"
/>
```

### Props

| Prop                   | Type                 | Default     | Description                                            |
| ---------------------- | -------------------- | ----------- | ------------------------------------------------------ |
| `modelValue`           | `string \| string[]` | —           | Selected value(s)                                      |
| `options`              | `ComboBoxOption[]`   | `[]`        | `{ label: string; value: string; disabled?: boolean }` |
| `placeholder`          | `string`             | `'Search…'` | Placeholder text                                       |
| `openOnFocus`          | `boolean`            | `false`     | Open the dropdown when the input is focused            |
| `hint`                 | `string`             | —           | Helper text                                            |
| + all `BaseFieldProps` |                      |             |                                                        |

**Formwerk composable:** `useComboBox` + `useDefaultFilter` — built-in `contains` filtering, `role="combobox"`.

## UiTagsField

Token/tag input. Type a value and press Enter or comma to add it as a tag. Backspace removes the last tag.

```html
<UiTagsField
  name="skills"
  label="Skills"
  placeholder="Add a skill…"
  hint="Press Enter or comma to add, Backspace to remove"
  :max-tags="10"
/>

<!-- Allow duplicate tags -->
<UiTagsField name="keywords" label="Keywords" placeholder="Add keyword…" :allow-duplicates="true" />
```

### Props

| Prop                   | Type       | Default      | Description                                |
| ---------------------- | ---------- | ------------ | ------------------------------------------ |
| `modelValue`           | `string[]` | `[]`         | Current list of tags                       |
| `placeholder`          | `string`   | `'Add tag…'` | Placeholder in the input area              |
| `hint`                 | `string`   | —            | Helper text                                |
| `maxTags`              | `number`   | —            | Maximum number of tags allowed             |
| `allowDuplicates`      | `boolean`  | `false`      | Whether duplicate tag values are permitted |
| + all `BaseFieldProps` |            |              |                                            |

Each tag renders as a pill with a remove (✕) button. The container shows a focus ring when the input is active.

**Formwerk composable:** `useCustomField<string[]>` — custom state management with Enter/comma/Backspace key handling.

## UiTreeSelect

Hierarchical dropdown with expandable/collapsible tree nodes. Supports multi-select with count display.

```html
<UiTreeSelect
  name="category"
  label="Category"
  placeholder="Select a category…"
  :nodes="[
    {
      label: 'Electronics', value: 'electronics',
      children: [
        { label: 'Phones',  value: 'phones' },
        { label: 'Laptops', value: 'laptops' },
        { label: 'Tablets', value: 'tablets' },
      ],
    },
    {
      label: 'Clothing', value: 'clothing',
      children: [
        { label: 'Men',   value: 'men' },
        { label: 'Women', value: 'women' },
      ],
    },
    { label: 'Books', value: 'books' },
  ]"
  hint="Expand categories to see sub-items"
/>

<!-- Multi-select tree -->
<UiTreeSelect
  name="departments"
  label="Departments"
  :nodes="departmentTree"
  :multiple="true"
  placeholder="Select departments…"
/>
```

### Props

| Prop                   | Type                 | Default     | Description                      |
| ---------------------- | -------------------- | ----------- | -------------------------------- |
| `modelValue`           | `string \| string[]` | —           | Selected node value(s)           |
| `nodes`                | `TreeNode[]`         | `[]`        | Hierarchical options (see below) |
| `placeholder`          | `string`             | `'Select…'` | Placeholder text                 |
| `multiple`             | `boolean`            | `false`     | Allow multiple selections        |
| `hint`                 | `string`             | —           | Helper text                      |
| + all `BaseFieldProps` |                      |             |                                  |

### `TreeNode` type

| Field      | Type          | Description                     |
| ---------- | ------------- | ------------------------------- |
| `label`    | `string`      | Display text                    |
| `value`    | `string`      | Form value                      |
| `children` | `TreeNode[]?` | Nested child nodes (expandable) |
| `disabled` | `boolean?`    | Disables this node              |

Multi-select shows a count badge (e.g. "3 selected"). The dropdown renders `role="tree"` with expand/collapse toggles.

**Formwerk composable:** `useCustomField<string | string[]>`.

## UiFileUpload

Drag-and-drop file picker with file list display and size information.

```html
<!-- Single file -->
<UiFileUpload
  name="resume"
  label="Upload résumé"
  accept=".pdf,.docx"
  hint="PDF or DOCX, max 10 MB"
  :max-size="10485760"
/>

<!-- Multiple images -->
<UiFileUpload
  name="gallery"
  label="Product photos"
  accept="image/*"
  :multiple="true"
  hint="Drag and drop files here, or click to browse"
/>
```

### Props

| Prop                   | Type      | Default | Description                                                     |
| ---------------------- | --------- | ------- | --------------------------------------------------------------- |
| `accept`               | `string`  | —       | Accepted MIME types or extensions (`"image/*"`, `".pdf,.docx"`) |
| `multiple`             | `boolean` | `false` | Allow selecting multiple files                                  |
| `maxSize`              | `number`  | —       | Maximum file size in bytes                                      |
| `hint`                 | `string`  | —       | Helper text                                                     |
| + all `BaseFieldProps` |           |         |                                                                 |

The upload zone features a dashed border container with visual feedback on drag-over and a file list showing names and sizes after selection.

**Formwerk composable:** `useFileField` — provides `dropzoneProps` for drag-and-drop handling.

## UiOTPField

Split-digit verification code input. Each digit occupies its own box. Auto-advances on entry, Backspace steps back.

```html
<!-- 6-digit numeric code (default) -->
<UiOTPField
  name="verifyCode"
  label="Verification code"
  :length="6"
  hint="Check your email for the 6-digit code"
/>

<!-- 4-digit alphanumeric code -->
<UiOTPField
  name="shortCode"
  label="Invite code"
  :length="4"
  accept="alphanumeric"
  hint="Letters and numbers accepted"
/>
```

### Props

| Prop                                   | Type                                   | Default     | Description              |
| -------------------------------------- | -------------------------------------- | ----------- | ------------------------ |
| `length`                               | `number`                               | `6`         | Number of input slots    |
| `accept`                               | `'numeric' \| 'alphanumeric' \| 'all'` | `'numeric'` | Allowed input characters |
| `hint`                                 | `string`                               | —           | Helper text              |
| + all `BaseFieldProps` (except `size`) |                                        |             |                          |

Each slot renders as a separate `<input>` with monospace font, centered text, and `aria-label` indicating the digit position.

**Formwerk composable:** `useOtpField` — provides `fieldSlots` array, auto-advance, and paste support.
