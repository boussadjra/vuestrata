# Text Inputs

Text input fields handle single-line and multi-line text entry. All share the same label, hint, and error rendering pattern.

::component-showcase{name="text-inputs"}
::

---

## UiTextField

Single-line text input supporting five HTML input types with Formwerk's `useTextField` under the hood.

```html
<!-- Basic text input -->
<UiTextField
  name="username"
  label="Username"
  placeholder="e.g. johndoe"
  hint="3–20 characters, letters and numbers only"
  required
/>

<!-- Email with validation -->
<UiTextField
  name="email"
  label="Email address"
  type="email"
  placeholder="you@example.com"
  hint="We'll never share your email"
  :schema="z.string().email('Please enter a valid email')"
  required
/>

<!-- Password -->
<UiTextField
  name="password"
  label="Password"
  type="password"
  placeholder="••••••••"
  hint="At least 8 characters"
  required
/>

<!-- Phone number -->
<UiTextField name="phone" label="Phone number" type="tel" placeholder="+1 (555) 000-0000" />

<!-- URL -->
<UiTextField name="website" label="Website" type="url" placeholder="https://example.com" />
```

### Props

| Prop                   | Type                                                | Default  | Description                                                          |
| ---------------------- | --------------------------------------------------- | -------- | -------------------------------------------------------------------- |
| `modelValue`           | `string`                                            | `''`     | Current input value (two-way via `v-model`)                          |
| `type`                 | `'text' \| 'email' \| 'password' \| 'tel' \| 'url'` | `'text'` | HTML input type — affects keyboard, autocomplete, and validation     |
| `placeholder`          | `string`                                            | —        | Placeholder text shown when the field is empty                       |
| `hint`                 | `string`                                            | —        | Helper text below the input                                          |
| + all `BaseFieldProps` |                                                     |          | `label`, `name`, `error`, `required`, `disabled`, `readonly`, `size` |

**Formwerk composable:** `useTextField` — provides `inputProps`, `labelProps`, `errorMessageProps`, `descriptionProps`.

## UiSearchField

Specialized search input with a built-in clear button and dedicated `search`/`clear` events.

```html
<UiSearchField
  name="query"
  label="Search products"
  placeholder="Search by name, SKU, or category…"
  hint="Press Enter to search"
  clear-button-label="Clear search"
  @search="performSearch"
  @clear="resetResults"
/>
```

### Props

| Prop                   | Type     | Default   | Description                               |
| ---------------------- | -------- | --------- | ----------------------------------------- |
| `modelValue`           | `string` | `''`      | Current search query                      |
| `placeholder`          | `string` | —         | Placeholder text                          |
| `hint`                 | `string` | —         | Helper text below the input               |
| `clearButtonLabel`     | `string` | `'Clear'` | Accessible label for the clear (✕) button |
| + all `BaseFieldProps` |          |           |                                           |

### Events

| Event               | Payload  | Description                            |
| ------------------- | -------- | -------------------------------------- |
| `update:modelValue` | `string` | Fires on every keystroke               |
| `search`            | `string` | Fires when the user presses Enter      |
| `clear`             | —        | Fires when the clear button is clicked |

**Formwerk composable:** `useSearchField` — adds `role="searchbox"` and a conditionally visible clear button.

## UiNumberField

Numeric input with increment/decrement buttons, locale-aware formatting, and `Intl.NumberFormat` support.

```html
<!-- Basic number field -->
<UiNumberField
  name="quantity"
  label="Quantity"
  placeholder="1"
  :min="1"
  :max="99"
  :step="1"
  required
/>

<!-- Currency with locale formatting -->
<UiNumberField
  name="price"
  label="Unit price"
  :min="0"
  :step="0.01"
  locale="en-US"
  :format-options="{ style: 'currency', currency: 'USD' }"
  hint="Enter the price in USD"
/>

<!-- Percentage -->
<UiNumberField
  name="discount"
  label="Discount"
  :min="0"
  :max="100"
  :step="5"
  hint="0–100%"
  size="sm"
/>
```

### Props

| Prop                   | Type                       | Default | Description                                              |
| ---------------------- | -------------------------- | ------- | -------------------------------------------------------- |
| `modelValue`           | `number`                   | —       | Current numeric value                                    |
| `placeholder`          | `string`                   | —       | Placeholder text                                         |
| `hint`                 | `string`                   | —       | Helper text                                              |
| `min`                  | `number`                   | —       | Minimum allowed value                                    |
| `max`                  | `number`                   | —       | Maximum allowed value                                    |
| `step`                 | `number`                   | `1`     | Increment/decrement step size                            |
| `locale`               | `string`                   | —       | BCP 47 locale tag for number formatting (e.g. `'de-DE'`) |
| `formatOptions`        | `Intl.NumberFormatOptions` | —       | Formatting options (currency, percent, etc.)             |
| + all `BaseFieldProps` |                            |         |                                                          |

**Formwerk composable:** `useNumberField` — provides `−` / `+` buttons, `inputmode="numeric"`, and Intl-aware display.

## UiTextarea

Multi-line text input with configurable row count, max length, and resize behavior.

```html
<!-- Basic textarea -->
<UiTextarea
  name="message"
  label="Message"
  placeholder="Tell us more…"
  hint="Be as detailed as possible"
  :rows="4"
  required
/>

<!-- Bio with character limit -->
<UiTextarea
  name="bio"
  label="Bio"
  placeholder="Write a short bio about yourself"
  :rows="3"
  :maxlength="500"
  hint="Max 500 characters"
  resize="vertical"
/>

<!-- Non-resizable -->
<UiTextarea name="notes" label="Internal notes" placeholder="Add notes…" :rows="6" resize="none" />
```

### Props

| Prop                   | Type                             | Default      | Description                |
| ---------------------- | -------------------------------- | ------------ | -------------------------- |
| `modelValue`           | `string`                         | `''`         | Current text value         |
| `placeholder`          | `string`                         | —            | Placeholder text           |
| `hint`                 | `string`                         | —            | Helper text                |
| `rows`                 | `number`                         | `4`          | Visible row count (height) |
| `maxlength`            | `number`                         | —            | Maximum character count    |
| `resize`               | `'none' \| 'vertical' \| 'both'` | `'vertical'` | CSS resize behavior        |
| + all `BaseFieldProps` |                                  |              |                            |

**Formwerk composable:** `useTextField` (reused — textarea is a multiline text field).
