# Date & Time

All date/time fields use Formwerk's segment-based editing powered by `@internationalized/date`. Each segment (month, day, year, hour, minute, AM/PM) is independently focusable and editable with arrow keys.

::component-showcase{name="date-time"}
::

---

## UiDateField

Segmented date input where each part (month, day, year) can be edited independently.

```html
<!-- Basic date -->
<UiDateField
  name="birthday"
  label="Date of birth"
  hint="Use arrow keys to navigate between segments"
/>

<!-- Constrained date range -->
<UiDateField
  name="eventDate"
  label="Event date"
  min="2026-01-01"
  max="2026-12-31"
  hint="Must be within 2026"
  required
/>

<!-- Islamic calendar (Hijri) -->
<UiDateField name="hijriDate" label="Hijri date" calendar="islamic-civil" />

<!-- Custom locale format -->
<UiDateField
  name="deadline"
  label="Deadline"
  locale="de-DE"
  :format-options="{ year: 'numeric', month: 'long', day: 'numeric' }"
/>
```

### Props

| Prop                   | Type                         | Default | Description                                                                     |
| ---------------------- | ---------------------------- | ------- | ------------------------------------------------------------------------------- |
| `modelValue`           | `Date`                       | —       | Selected date                                                                   |
| `locale`               | `string`                     | —       | BCP 47 locale for formatting                                                    |
| `calendar`             | `string`                     | —       | Calendar system (`'gregory'`, `'islamic-civil'`, `'persian'`, `'hebrew'`, etc.) |
| `timeZone`             | `string`                     | —       | IANA time zone (e.g. `'America/New_York'`)                                      |
| `formatOptions`        | `Intl.DateTimeFormatOptions` | —       | Customize segment display                                                       |
| `placeholder`          | `string`                     | —       | Placeholder text                                                                |
| `min`                  | `string`                     | —       | Minimum date (ISO 8601)                                                         |
| `max`                  | `string`                     | —       | Maximum date (ISO 8601)                                                         |
| `hint`                 | `string`                     | —       | Helper text                                                                     |
| + all `BaseFieldProps` |                              |         |                                                                                 |

**Formwerk composable:** `useDateField` — provides `DateTimeSegment` components with accessible segment navigation.

## UiTimeField

Segmented time input with independent hour, minute, and AM/PM segments.

```html
<!-- Basic time -->
<UiTimeField name="startTime" label="Start time" hint="Select a time" />

<!-- 12-hour format -->
<UiTimeField name="alarm" label="Alarm" :hour12="true" hint="Includes AM/PM selector" />

<!-- Custom locale -->
<UiTimeField
  name="meetingTime"
  label="Meeting time"
  locale="de-DE"
  :format-options="{ hour: '2-digit', minute: '2-digit' }"
/>
```

### Props

| Prop                   | Type                         | Default | Description                     |
| ---------------------- | ---------------------------- | ------- | ------------------------------- |
| `modelValue`           | `string`                     | —       | Time value as string            |
| `locale`               | `string`                     | —       | BCP 47 locale                   |
| `hour12`               | `boolean`                    | —       | Force 12-hour format with AM/PM |
| `formatOptions`        | `Intl.DateTimeFormatOptions` | —       | Customize segment display       |
| `placeholder`          | `string`                     | —       | Placeholder text                |
| `hint`                 | `string`                     | —       | Helper text                     |
| + all `BaseFieldProps` |                              |         |                                 |

**Formwerk composable:** `useTimeField` — segment-based editing with arrow key increment/decrement.

## UiDatePicker

Date field with a popup calendar. Combines `useDateField` + `usePicker`.

```html
<UiDatePicker name="dueDate" label="Due date" hint="Click the calendar icon to pick a date" />

<UiDatePicker name="appointmentDate" label="Appointment" min="2026-01-01" required />
```

Props are identical to `UiDateField`. The calendar trigger button opens a `UiCalendar` popup for visual date selection.

---

## UiDatetimePicker

Combined date and time selection with a calendar popup that includes both date and time segments.

```html
<UiDatetimePicker name="eventStart" label="Event start" hint="Select both date and time" />

<UiDatetimePicker
  name="deadline"
  label="Deadline"
  :hour12="true"
  :format-options="{ year: 'numeric', month: '2-digit', day: '2-digit', hour: '2-digit', minute: '2-digit' }"
/>
```

### Props

| Prop                    | Type      | Default | Description          |
| ----------------------- | --------- | ------- | -------------------- |
| All `UiDateField` props |           |         | Date props apply     |
| `hour12`                | `boolean` | —       | Force 12-hour format |

## Range pickers

### UiDateRangePicker

Two date pickers for selecting a start and end date.

```html
<UiDateRangePicker name="vacation" label="Vacation period" hint="Select start and end dates" />
```

| Prop                                            | Type   | Description                                                   |
| ----------------------------------------------- | ------ | ------------------------------------------------------------- |
| `start` / `end`                                 | `Date` | Range endpoints (two-way via `v-model:start` / `v-model:end`) |
| + all `UiDateField` props (except `modelValue`) |        |                                                               |

### UiTimeRangePicker

Two time fields for start and end time.

```html
<UiTimeRangePicker
  name="businessHours"
  label="Business hours"
  hint="Select opening and closing time"
/>
```

| Prop                                            | Type     | Description     |
| ----------------------------------------------- | -------- | --------------- |
| `start` / `end`                                 | `string` | Range endpoints |
| + all `UiTimeField` props (except `modelValue`) |          |                 |

## Month & year pickers

### UiMonthPicker

Month and year selection with a 12-month grid popup.

```html
<UiMonthPicker name="billingCycle" label="Billing cycle" hint="Select the month" />
```

Default `formatOptions`: `{ year: 'numeric', month: 'long' }`. All date props apply.

### UiMonthRangePicker

Two month pickers for selecting a month range.

```html
<UiMonthRangePicker name="fiscalPeriod" label="Fiscal period" hint="From and to month" />
```

### UiYearPicker

Year-only selection with a decade grid popup.

```html
<UiYearPicker name="graduationYear" label="Graduation year" hint="Select the year" />
```

### UiYearRangePicker

Two year pickers for selecting a year range.

```html
<UiYearRangePicker name="reportYears" label="Report period" hint="Select start and end year" />
```

---

## UiCalendar (standalone)

A standalone calendar grid for custom pickers or inline date displays without the field wrapper.

```html
<UiCalendar label="Select a date" @change="selectedDate = $event" />
```

The calendar renders three switchable views via navigation buttons: **Weeks** (default) → **Months** → **Years**.
