These components handle specialized data types — ranges, colors, inline editing, mentions, ratings, and multi-step flows.

## UiSlider

Single-thumb range slider with drag and keyboard support. Shows the current value in an `<output>` element.

```html
<!-- Volume control -->
<UiSlider
  name="volume"
  label="Volume"
  :min="0"
  :max="100"
  :step="5"
  hint="Drag the thumb or use arrow keys"
/>

<!-- Temperature with fine control -->
<UiSlider name="temperature" label="Temperature (°C)" :min="-20" :max="50" :step="0.5" />
```

### Props

| Prop                   | Type                         | Default        | Description      |
| ---------------------- | ---------------------------- | -------------- | ---------------- |
| `modelValue`           | `number`                     | `0`            | Current value    |
| `min`                  | `number`                     | `0`            | Minimum value    |
| `max`                  | `number`                     | `100`          | Maximum value    |
| `step`                 | `number`                     | `1`            | Step increment   |
| `orientation`          | `'horizontal' \| 'vertical'` | `'horizontal'` | Slider direction |
| `hint`                 | `string`                     | —              | Helper text      |
| + all `BaseFieldProps` |                              |                |                  |

**Formwerk composable:** `useSlider` + `useSliderThumb` — `role="slider"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`.

## UiRangeSlider

Dual-thumb slider for selecting a value range (e.g. price range).

```html
<UiRangeSlider
  name="priceRange"
  label="Price range"
  :min="0"
  :max="1000"
  :step="10"
  hint="Drag both thumbs to set the range"
/>

<UiRangeSlider name="ageRange" label="Age range" :min="18" :max="65" :step="1" />
```

### Props

| Prop                   | Type     | Default | Description       |
| ---------------------- | -------- | ------- | ----------------- |
| `start`                | `number` | —       | Lower bound value |
| `end`                  | `number` | —       | Upper bound value |
| `min`                  | `number` | `0`     | Minimum value     |
| `max`                  | `number` | `100`   | Maximum value     |
| `step`                 | `number` | `1`     | Step increment    |
| + all `BaseFieldProps` |          |         |                   |

### Events

| Event          | Payload  | Description         |
| -------------- | -------- | ------------------- |
| `update:start` | `number` | Lower bound changed |
| `update:end`   | `number` | Upper bound changed |

Renders a filled track segment between the two thumbs.

**Formwerk composable:** `useSlider` + two `useSliderThumb` calls.

## UiColorPicker

Color selection with a native `<input type="color">`, hex display, and optional preset swatches.

```html
<!-- Basic color picker -->
<UiColorPicker name="accentColor" label="Accent color" hint="Click the swatch to open the picker" />

<!-- With preset swatches -->
<UiColorPicker
  name="brandColor"
  label="Brand color"
  :swatches="['#6366f1', '#8b5cf6', '#ec4899', '#f43f5e', '#f97316', '#eab308', '#22c55e']"
  format="hex"
  hint="Choose from presets or pick a custom color"
/>
```

### Props

| Prop                   | Type                      | Default     | Description                                        |
| ---------------------- | ------------------------- | ----------- | -------------------------------------------------- |
| `modelValue`           | `string`                  | `'#000000'` | Color value in the specified format                |
| `swatches`             | `string[]`                | —           | Predefined color values shown as clickable circles |
| `format`               | `'hex' \| 'rgb' \| 'hsl'` | `'hex'`     | Output format                                      |
| `hint`                 | `string`                  | —           | Helper text                                        |
| + all `BaseFieldProps` |                           |             |                                                    |

Selected swatch gets a ring highlight. The hex value is shown in monospace next to the color input.

**Formwerk composable:** `useCustomField<string>`.

## UiEditable

Inline click-to-edit text. Displays as plain text until clicked, then transforms into an input.

```html
<UiEditable
  name="pageTitle"
  label="Page title"
  placeholder="Click to edit…"
  hint="Click the text to start editing"
/>
```

### Props

| Prop                   | Type     | Default | Description                   |
| ---------------------- | -------- | ------- | ----------------------------- |
| `modelValue`           | `string` | `''`    | Current text value            |
| `placeholder`          | `string` | —       | Shown when the value is empty |
| `hint`                 | `string` | —       | Helper text                   |
| + all `BaseFieldProps` |          |         |                               |

### Interaction model

1. **Display mode** — text renders as a styled `<span>` (hover shows underline)
2. **Edit mode** — click the span → `<input>` appears with `autofocus`
3. **Confirm** — Enter or blur saves the value
4. **Cancel** — Escape reverts to the previous value

**Formwerk composable:** `useCustomField<string>`.

## UiMentionsField

Textarea with an `@`-mention popup. Type the trigger character to open a suggestions dropdown.

```html
<UiMentionsField
  name="comment"
  label="Comment"
  placeholder="Write a comment… type @ to mention someone"
  :mentions="[
    { id: '1', label: 'Alice Chen',  avatar: '/avatars/alice.jpg' },
    { id: '2', label: 'Bob Müller',  avatar: '/avatars/bob.jpg' },
    { id: '3', label: 'Charlie Park' },
  ]"
  trigger="@"
  hint="Use @ to mention team members"
/>
```

### Props

| Prop                   | Type            | Default | Description                                |
| ---------------------- | --------------- | ------- | ------------------------------------------ |
| `modelValue`           | `string`        | `''`    | Full text value including mention markup   |
| `placeholder`          | `string`        | —       | Placeholder text                           |
| `mentions`             | `MentionItem[]` | `[]`    | Available mention targets                  |
| `trigger`              | `string`        | `'@'`   | Character that opens the suggestions popup |
| `hint`                 | `string`        | —       | Helper text                                |
| + all `BaseFieldProps` |                 |         |                                            |

### `MentionItem` type

| Field    | Type      | Description                     |
| -------- | --------- | ------------------------------- |
| `id`     | `string`  | Unique identifier               |
| `label`  | `string`  | Display name shown in the popup |
| `avatar` | `string?` | Avatar image URL                |

**Formwerk composable:** `useCustomField<string>`.

## UiRatingField

Star rating input with hover preview and optional half-star support.

```html
<!-- 5-star rating -->
<UiRatingField
  name="satisfaction"
  label="How satisfied are you?"
  :max="5"
  hint="Click a star to rate"
/>

<!-- 10-star rating with half stars -->
<UiRatingField name="quality" label="Product quality" :max="10" :allow-half="true" />
```

### Props

| Prop                   | Type      | Default | Description                 |
| ---------------------- | --------- | ------- | --------------------------- |
| `modelValue`           | `number`  | `0`     | Current rating value        |
| `max`                  | `number`  | `5`     | Number of stars             |
| `allowHalf`            | `boolean` | `false` | Enable half-star increments |
| `hint`                 | `string`  | —       | Helper text                 |
| + all `BaseFieldProps` |           |         |                             |

Stars render yellow (★) when filled. Hovering previews the rating. Renders `role="radiogroup"` with per-star `aria-label`.

**Formwerk composable:** `useCustomField<number>`.

## UiSteppedForm

Multi-step form wizard with a step indicator, navigation buttons, and per-step content via named slots.

```html
<UiSteppedForm next-label="Continue" previous-label="Go back" @done="handleFinalSubmit">
  <template #step-0>
    <h2>Account</h2>
    <UiTextField name="email" label="Email" type="email" placeholder="you@example.com" required />
    <UiTextField name="password" label="Password" type="password" placeholder="••••••••" required />
  </template>

  <template #step-1>
    <h2>Profile</h2>
    <UiTextField name="firstName" label="First name" placeholder="Jane" required />
    <UiTextField name="lastName" label="Last name" placeholder="Doe" required />
    <UiTextarea name="bio" label="Bio" placeholder="Tell us about yourself" :rows="3" />
  </template>

  <template #step-2>
    <h2>Confirm</h2>
    <p>Please review your details before submitting.</p>
  </template>
</UiSteppedForm>
```

### Props

| Prop            | Type     | Default      | Description               |
| --------------- | -------- | ------------ | ------------------------- |
| `nextLabel`     | `string` | `'Next'`     | Text on the "next" button |
| `previousLabel` | `string` | `'Previous'` | Text on the "back" button |

### Events

| Event  | Payload   | Description                                          |
| ------ | --------- | ---------------------------------------------------- |
| `done` | `unknown` | Fires when the user clicks "Submit" on the last step |

**Step indicator:** Numbered circles with connecting progress bars. Completed steps show a filled indicator.

**Navigation:** Previous/Next buttons. The last step shows "Submit" instead of "Next". Steps are defined via `#step-0`, `#step-1`, etc.

**Formwerk composable:** `useStepFormFlow`.
