# Charts

Vuestrata integrates ECharts via `vue-echarts` with automatic theme awareness. Charts adapt to the active theme and dark mode.

::component-showcase{name="charts"}
::

## Basic Usage

```vue
<script setup lang="ts">
import { ref } from 'vue'

const chartOptions = ref({
  xAxis: {
    type: 'category',
    data: ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'],
  },
  yAxis: { type: 'value' },
  series: [
    {
      data: [150, 230, 224, 218, 135],
      type: 'line',
      smooth: true,
    },
  ],
})
</script>

<template>
  <BaseChart :option="chartOptions" style="height: 300px" />
</template>
```

## Chart Gallery

The `/dashboard/charts` page includes **52 examples across eight families**. Search by chart name or use case, or select a family to compare related approaches. Every example includes deterministic sample data and a keyboard-accessible **View data** table. Titles, chart labels and sample tables are available in English, French and Arabic.

| Family       | Examples | What you can explore                                                                          |
| ------------ | -------- | --------------------------------------------------------------------------------------------- |
| Trends       | 8        | Straight, smooth and stepped lines, areas, percentage stacks, multiple series and dual axes   |
| Comparison   | 10       | Columns, grouped and stacked bars, diverging values, waterfalls, lollipops and pictorial bars |
| Composition  | 6        | Pie, donut, rose, nested and semicircular breakdowns                                          |
| Distribution | 6        | Histograms, vertical and horizontal boxplots, candlesticks and two heatmaps                   |
| Relationship | 6        | Scatter, bubble and highlighted points, fitted regression, quadrants and parallel coordinates |
| Hierarchy    | 6        | Flat and nested treemaps, sunburst, horizontal and radial trees, and a network graph          |
| Flow         | 4        | Sankey, single and paired funnels, and a circular network                                     |
| Monitoring   | 6        | Full and semicircular gauges, multiple progress rings, two radars and polar bars              |

Charts mount when their panels approach the viewport. Search and family filters keep the full collection easy to browse without drawing every canvas on entry. Chart options and their data tables are built together in `src/modules/analytics/lib/chart-gallery.ts`; the route page only renders the gallery screen.

## Theme Awareness

The gallery resolves chart colors, axes, legends, tooltips and typography from the active theme. Its options update when the theme or language changes. `BaseChart` renders the options its caller supplies, handles resizing and reduced motion, and provides an accessible name and optional data-table equivalent.

```vue
<template>
  <!-- Supply reactive, theme-aware options from the owning feature. -->
  <BaseChart :option="options" />
</template>
```

Build options with `useThemeColors()` or the analytics module's `useChartColors()` helper. The gallery uses:

- `--color-chart-1` through `--color-chart-8` for distinct series.
- `--color-foreground` and `--color-muted-foreground` for text.
- `--color-border` for axes and grid lines.
- `--color-elevated` for tooltip surfaces and segment separators.

Keep registration of additional ECharts types in the lazy gallery renderer. Importing its registration module from a module barrel or application bootstrap would make the larger charting bundle load on pages that contain no charts.
