# Charts

Vuestrata integrates ECharts via `vue-echarts` with automatic theme awareness. Charts adapt to the active theme and dark mode.

::component-showcase{name="charts"}
::

## Basic Usage

```vue
<script setup lang="ts">
import { ref } from 'vue'

const chartOptions = ref({
  xAxis: {
    type: 'category',
    data: ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'],
  },
  yAxis: { type: 'value' },
  series: [
    {
      data: [150, 230, 224, 218, 135],
      type: 'line',
      smooth: true,
    },
  ],
})
</script>

<template>
  <BaseChart :option="chartOptions" style="height: 300px" />
</template>
```

## Chart Types

The dashboard showcases 8 chart types:

| Type        | Use Case                       |
| ----------- | ------------------------------ |
| Area Line   | Revenue trends, time series    |
| Stacked Bar | Category comparisons           |
| Donut/Pie   | Distribution breakdowns        |
| Radar       | Multi-dimensional comparison   |
| Scatter     | Correlation analysis           |
| Gauge       | KPI progress                   |
| Treemap     | Hierarchical data              |
| Heatmap     | Activity/density visualization |

## Theme Awareness

`BaseChart` automatically responds to theme changes. Chart colors, backgrounds, and text adjust to match the current theme's CSS custom properties.

```vue
<template>
  <!-- Chart automatically uses theme colors -->
  <BaseChart :option="options" />
</template>
```

The chart component reads the following theme tokens:

- `--color-primary-*` for primary series
- `--color-accent-*` for secondary series
- `--color-surface-*` for backgrounds and axes
