# Components

Vuestrata provides a Reka-based `Ui*` component set. Each wrapper exposes the public component contract used throughout the app while shared field behaviour lives in `src/modules/app/composables/forms/`.

## Component List

Looking for detailed form management? Open [Form Builder](/docs/components/forms/form-builder).

## Usage

::component-showcase{name="overview"}
::

All components use a consistent API across the wrapper layer:

```vue
<script setup lang="ts">
import { ref } from 'vue'

const name = ref('')
const agreed = ref(false)
const dialogOpen = ref(false)
</script>

<template>
  <UiCard>
    <template #header>Form Example</template>

    <UiTextField v-model="name" label="Name" placeholder="Enter name" />
    <UiCheckbox v-model="agreed" label="I agree to the terms" />

    <template #footer>
      <UiButton variant="primary" @click="dialogOpen = true"> Submit </UiButton>
    </template>
  </UiCard>

  <UiDialog v-model:open="dialogOpen">
    <template #title>Confirmation</template>
    <p>Your form has been submitted.</p>
  </UiDialog>
</template>
```

## Auto-Import

All UI components are auto-imported via `unplugin-vue-components`. No manual imports needed.

## Wrapper Structure

`Ui*` files are the public import surface in `src/modules/app/components/ui/`. When a component needs shared state, Formwerk bindings, or reusable rendering helpers, that logic lives under `src/modules/app/composables/forms/` and is composed by the wrapper.
