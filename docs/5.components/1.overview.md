# Components

Vuestrata provides an adapter-based UI component set. Each component delegates rendering to the active UI provider (Reka UI by default).

## Component List

Looking for detailed form management? Open [Form Builder](/docs/components/forms/form-builder).

### Data Display

| Component     | Description                                                |
| ------------- | ---------------------------------------------------------- |
| `UiAvatar`    | User avatar with fallback initials                         |
| `UiBadge`     | Status badges and labels                                   |
| `UiCard`      | Content container with header/footer slots                 |
| `UiDataTable` | TanStack Table wrapper with sorting, filtering, pagination |
| `UiSkeleton`  | Loading placeholder                                        |
| `UiSeparator` | Horizontal or vertical divider                             |

## Usage

::component-showcase{name="overview"}
::

All components use a consistent API regardless of the underlying provider:

```vue
<script setup lang="ts">
import { ref } from 'vue'

const name = ref('')
const agreed = ref(false)
const dialogOpen = ref(false)
</script>

<template>
  <UiCard>
    <template #header>Form Example</template>

    <UiTextField v-model="name" label="Name" placeholder="Enter name" />
    <UiCheckbox v-model="agreed" label="I agree to the terms" />

    <template #footer>
      <UiButton variant="primary" @click="dialogOpen = true"> Submit </UiButton>
    </template>
  </UiCard>

  <UiDialog v-model:open="dialogOpen">
    <template #title>Confirmation</template>
    <p>Your form has been submitted.</p>
  </UiDialog>
</template>
```

## Auto-Import

All UI components are auto-imported via `unplugin-vue-components`. No manual imports needed.

## Creating a Provider Implementation

To add a new UI provider, create a directory under `src/modules/app/components/ui/provider/`:

```
src/modules/app/components/ui/provider/mylib/
├── MyLibButton.vue
├── MyLibCard.vue
├── MyLibDialog.vue
└── ... (one file per adapter component)
```

Then register the provider in `src/modules/app/config/ui-provider.ts`:

```ts
export const providers = {
  reka: () => import('./provider/reka'),
  vuetify0: () => import('./provider/vuetify0'),
  mylib: () => import('./provider/mylib'),
}
```
