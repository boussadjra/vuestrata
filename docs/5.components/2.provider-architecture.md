# Provider Architecture

Vuestrata supports multiple UI providers behind a single set of `Ui*` wrapper components. Each provider implements the same contract (props, emits, slots) using a different headless component library, letting consumers switch providers without changing application code.

## Dual-Provider Model

| Provider | Directory                                          | Headless library | Strategy                                                           |
| -------- | -------------------------------------------------- | ---------------- | ------------------------------------------------------------------ |
| **Reka** | `src/modules/app/components/ui/provider/reka/`     | `reka-ui`        | Wraps Reka UI primitives                                           |
| **V0**   | `src/modules/app/components/ui/provider/vuetify0/` | `@vuetify/v0`    | Wraps Vuetify 0 compound components; standalone for presentational |

The active provider is selected at runtime via `src/modules/app/config/ui-provider.ts`. `Ui*` wrappers in `src/modules/app/components/ui/` call `resolveUiComponent()` and forward all props, emits, and slots to whichever provider is active.

## Shared Types

Both providers import type interfaces from `src/modules/app/types/index.ts`:

- `AccordionItemData` — accordion item shape
- `BreadcrumbItem` — breadcrumb node shape
- `CommandItem` — command palette item shape
- `StepperItem` — stepper step shape
- `TabItem` — tab definition shape

Reka components re-export these types for backward compatibility.

## Adding a New V0 Component

1. Create `src/modules/app/components/ui/provider/vuetify0/V0<Name>.vue`.
2. Import the compound component from `@vuetify/v0` (e.g., `import { Dialog } from '@vuetify/v0'`).
3. Use the dot-notation API: `Dialog.Root > Dialog.Activator + Dialog.Content`.
4. Apply Tailwind classes matching the Reka visual contract.
5. Import shared types from `~/types`, not from `../reka/`.
6. Ensure zero imports from the `reka/` directory (Constitution Principle XVIII).
7. Add a test in `test/v0-components.test.ts`.

## CSS Anchor Positioning

V0 Popover and Tooltip use `@vuetify/v0`'s CSS Anchor Positioning for floating placement via `position-area` and `position-try`. Browser support:

- Chrome 125+, Edge 125+
- Firefox 147+ (beta)
- Safari: not yet supported

See the [@vuetify/v0 Popover documentation](https://0.vuetifyjs.com/components/popover) for polyfill and fallback guidance.
