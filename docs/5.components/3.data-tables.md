# Data Tables

The `useDataTable` composable wraps TanStack Table with a Vue-friendly API, providing sorting, filtering, pagination, row selection, column visibility, grouping, and expanding.

::component-showcase{name="data-table"}
::

## Basic Usage

```ts
import { useDataTable } from '~/composables/useDataTable'
import type { ColumnDef } from '@tanstack/vue-table'

interface User {
  id: string
  name: string
  email: string
  role: string
}

const columns: ColumnDef<User>[] = [
  { accessorKey: 'name', header: 'Name' },
  { accessorKey: 'email', header: 'Email' },
  { accessorKey: 'role', header: 'Role' },
]

const { table, globalFilter, pagination } = useDataTable({
  data: users,
  columns,
  pageSize: 10,
})
```

```vue
<template>
  <UiTextField v-model="globalFilter" placeholder="Search..." />
  <UiDataTable :table="table" />
</template>
```

## Features

### Sorting

Click column headers to toggle sorting. Multi-column sorting supported with shift-click.

### Filtering

- **Global filter** — Searches all columns
- **Column filter** — Per-column filter with custom filter functions

### Pagination

```ts
const { pagination, pageCount, canPreviousPage, canNextPage } = useDataTable({
  data: users,
  columns,
  pageSize: 25,
})
```

### Row Selection

```ts
const { selectedRows, selectedRowIds, toggleRowSelection } = useDataTable({
  data: users,
  columns,
  enableRowSelection: true,
})
```

### Column Visibility

```ts
const { columnVisibility, toggleColumnVisibility } = useDataTable({
  data: users,
  columns,
})

// Hide a column
toggleColumnVisibility('email', false)
```

### CSV Export

```ts
const { exportToCSV } = useDataTable({ data: users, columns })

// Download as CSV
exportToCSV('users-export.csv')
```
