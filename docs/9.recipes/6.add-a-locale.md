# Add a Locale

There is no generator for this — adding a language is mostly _translating_, and
a tool that produced 1,100 placeholder strings would create the illusion of a
finished translation. The mechanical parts are small and listed here.

## 1. Declare it

`src/modules/app/plugins/appearance.ts` owns the locale list — and, deliberately,
the metadata and RTL set beside it, so adding a language is one file:

```ts
export const SUPPORTED_LOCALES = ['en', 'fr', 'ar', 'de'] as const

export const LOCALE_METADATA: Record<SupportedLocale, { label: string; flag: string }> = {
  // …
  de: { label: 'Deutsch', flag: '🇩🇪' },
}

const RTL_LOCALES = new Set<SupportedLocale>(['ar']) // add here if RTL
```

`plugins/i18n.ts` imports `SUPPORTED_LOCALES` from there, so it needs no edit.

## 2. Add the catalog files

One per locale folder — the shell plus every module:

```
src/modules/app/locales/<locale>.json
src/modules/<each module>/i18n/<locale>.json
```

The Vite i18n plugin already globs `src/modules/app/locales/**` and
`src/modules/**/i18n/**`, so no config change is needed.

Import and expose the new file in each module's `index.ts`:

```ts
import paymentsI18nDe from './i18n/de.json'
// …
i18n: { en: …, fr: …, ar: …, de: paymentsI18nDe },
```

## 3. Translate every key

`i18n-parity` fails if any locale in a folder is missing a key another one has.
That is the point: vue-i18n falls back to `en` silently, so a gap looks like a
working build until a native speaker opens the page.

Fastest honest path: copy `en.json`, translate in place, keep the keys.

```bash
node scripts/lint/run-custom-rules.mjs   # tells you exactly which keys are missing
```

## RTL

If the language is right-to-left, adding it to `RTL_LOCALES` is enough for the
plumbing — `applyAppearance` sets `html.dir`. But _verify the layout_: Arabic is
already covered by `e2e/rtl-and-keyboard.spec.ts`, and directional CSS
(`ms-*`/`me-*` rather than `ml-*`/`mr-*`) matters. Add your locale to that spec.

## Verify

```bash
node scripts/lint/run-custom-rules.mjs   # i18n-parity
vp check && vp test --run
vp dev                                   # switch language in Settings
```
