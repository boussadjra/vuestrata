# Vuestrata

Vue 3 enterprise-grade template built on four pillars: **adapter-driven UI** (runtime provider switching between Reka UI and Vuetify), a **multi-theme engine** (dark mode and custom theme registration), **typed data boundaries** (ofetch client + TanStack Query + typed query-key factories), and a comprehensive **testing infrastructure** (Vitest + Playwright).
