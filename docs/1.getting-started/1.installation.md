# Installation

## Prerequisites

- [Node.js](https://nodejs.org/) v20 or later
- [Vite Plus](https://vite.dev/) (`vp` CLI)

## Quick Start

::code-group

```bash [vp]
# Clone the template
git clone https://github.com/user/vuestrata.git my-app
cd my-app

# Install dependencies
vp install

# Start dev server
vp dev
```

```bash [Docker]
# Build and run with Docker Compose
docker compose up --build
```

::

The dev server runs at [http://localhost:3333](http://localhost:3333) by default.

## Project Structure

```
src/
├── modules/
│   ├── app/             # Main application module
│   │   ├── assets/      # Static assets (fonts, images)
│   │   ├── components/  # UI components + layout shell
│   │   │   ├── layout/  # AppHeader, AppSidebar, AppFooter
│   │   │   └── ui/      # 55+ adapter-driven UI components
│   │   │       └── provider/  # Provider implementations (reka, vuetify0)
│   │   ├── composables/ # Composition functions (auth, RBAC, forms, tables)
│   │   ├── config/      # Runtime adapters — UI, icon, theme, validation providers
│   │   ├── layouts/     # Page layouts (default, auth, dashboard, blank)
│   │   ├── mocks/       # MSW mock handlers (auth, dashboard, billing, audit)
│   │   ├── pages/       # Vue Router file-based routes
│   │   ├── plugins/     # Vue plugins (router, pinia, i18n, vue-query)
│   │   ├── stores/      # Pinia stores — client-only state (auth, app, notification)
│   │   ├── styles/      # Tailwind CSS v4 + 10 theme presets + dark mode
│   │   └── types/       # Shared TypeScript types
│   ├── billing/         # Billing module (server state via TanStack Query)
│   ├── core/            # Core module — shared utilities
│   │   └── lib/         # Framework-agnostic utilities (api, errors, logger, rbac, etc.)
│   ├── settings/        # Settings module (client state via Pinia)
│   └── users/           # Users module (server state via TanStack Query)
```

## Available Scripts

| Command              | Description                        |
| -------------------- | ---------------------------------- |
| `vp dev`             | Start Vite dev server on port 3333 |
| `vp build`           | Type-check + production build      |
| `vp preview`         | Preview production build           |
| `vp check`           | Run format, lint, and typecheck    |
| `vp lint`            | Lint with oxlint                   |
| `vp lint --fix`      | Lint and auto-fix                  |
| `vp fmt`             | Format with oxfmt                  |
| `vp fmt --check`     | Check formatting without writing   |
| `vp test`            | Run Vitest in watch mode           |
| `vp test --run`      | Run Vitest once                    |
| `vp run test:e2e`    | Run Playwright e2e tests           |
| `vp run test:e2e:ui` | Run Playwright with interactive UI |
| `vp test --coverage` | Run tests with v8 coverage         |
| `vp run scaffold`    | Interactive scaffold CLI           |
| `vp outdated`        | Check for outdated packages        |
| `vp update`          | Update dependencies                |

## Scaffold CLI

Run `vp run scaffold` to interactively configure the template:

1. Select a **UI provider** (Reka UI or Vuetify)
2. Choose an **icon provider** (Solar, Lucide, Phosphor)
3. Pick a **theme** (9 built-in themes: Blueprint, Brutalist, Febin, Forest, Ghibli, Ocean, Rose, Sunset, Terminal)
4. Select a **validation adapter** (Zod, Valibot, Yup, ArkType)

The scaffold script prunes unused files and hard-codes your choices in the configuration files.
