# Configuration

## Environment Variables

Copy `.env.example` to `.env.local` in the project root and customise the values:

```bash
# Application title
VUESTRATA_APP_TITLE=Vuestrata

# API base URL
VUESTRATA_API_URL=http://localhost:3000/api

# Enable MSW mocks in development
VUESTRATA_USE_MOCKS=true

# Auth adapter: 'mock' | 'jwt' | 'oauth'
VUESTRATA_AUTH_ADAPTER=mock

# Icon Provider: 'solar' | 'lucide' | 'phosphor'
VUESTRATA_ICON_PROVIDER=solar
```

All environment variables are read in `src/modules/app/config/app.config.ts`. User-selected icon, theme, and locale preferences are then persisted through the app store.

## UI Components

The `Ui*` component layer is fixed to the repo's Reka UI implementation. There is no runtime UI-provider switch or environment key for swapping the component library.

## Icon Provider

Icons are resolved through a semantic adapter. Three built-in icon sets are available (`solar`, `lucide`, `phosphor`). Switch them through the settings page or the app store:

```ts
import { useAppStore } from '~/stores/app'

const appStore = useAppStore()

appStore.setIconProvider('lucide')
```

::alert{type="info"}
Custom icon maps can be registered at runtime via `registerIconMap(name, map)`.
::

## Validation

The template ships with Zod as the single supported schema library for forms and validation examples.

## Theme Configuration

Themes are managed via CSS custom properties and the `useTheme()` composable. Built-in themes: `default`, `brutalist`, `ghibli`, `ocean`, `sunset`, `forest`, `rose`, `terminal`, `blueprint`, `febin`.

```ts
const { currentTheme, currentThemeName, isDark, themes, setTheme, toggleDark, registerTheme } =
  useTheme()

// Set theme
setTheme('ocean')

// Toggle dark mode
toggleDark()

// Register a custom theme at runtime
registerTheme({ name: 'custom', label: 'Custom', cssClass: 'theme-custom' })
```

See the [Theming](/docs/theming/overview) section for complete details.
