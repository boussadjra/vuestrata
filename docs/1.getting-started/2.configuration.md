# Configuration

## Environment Variables

Copy `.env.example` to `.env.local` in the project root and customise the values:

```bash
# Application title
VUESTRATA_APP_TITLE=Vuestrata

# API base URL
VUESTRATA_API_URL=http://localhost:3000/api

# Enable MSW mocks in development
VUESTRATA_USE_MOCKS=true

# Auth adapter: 'mock' | 'jwt' | 'oauth'
VUESTRATA_AUTH_ADAPTER=mock

# UI Provider: 'reka' | 'vuetify0'
VUESTRATA_UI_PROVIDER=reka

# Icon Provider: 'solar' | 'lucide' | 'phosphor'
VUESTRATA_ICON_PROVIDER=solar

# Validation Adapter: 'zod' | 'valibot' | 'yup' | 'arktype'
VUESTRATA_VALIDATION_ADAPTER=zod
```

All environment variables are read in `src/modules/app/config/app.config.ts` and persisted through the app store, so runtime changes via the UI are also supported.

## UI Provider

The UI provider determines which component library renders the adapter components (Button, Card, Dialog, etc.). Set the default via `VUESTRATA_UI_PROVIDER` or change it at runtime:

```ts
import { useUiProvider } from '~/config/ui-provider'

const { provider, setProvider } = useUiProvider()

// Switch at runtime
setProvider('vuetify0')
```

Components are resolved dynamically via `resolveUiComponent(name)`, which maps to `Reka*` or `V0*` provider components under `src/modules/app/components/ui/provider/`.

## Icon Provider

Icons are resolved through a semantic adapter. Three built-in icon sets are available (`solar`, `lucide`, `phosphor`):

```ts
import { useIconProvider } from '~/config/icon-provider'

const { provider, setProvider } = useIconProvider()

// Switch at runtime
setProvider('lucide')
```

::alert{type="info"}
Custom icon maps can be registered at runtime via `registerIconMap(name, map)`.
::

## Validation Provider

Validation adapters are lazy-loaded for optimal bundle size:

```ts
import { useValidationProvider } from '~/config/validation-provider'

const { adapterName, setAdapter, getAdapter } = useValidationProvider()

// Switch at runtime
setAdapter('valibot')
```

Supported adapters: `zod`, `valibot`, `yup`, `arktype`.

## Theme Configuration

Themes are managed via CSS custom properties and the `useTheme()` composable. Built-in themes: `default`, `brutalist`, `ghibli`, `ocean`, `sunset`, `forest`, `rose`, `terminal`, `blueprint`, `febin`.

```ts
const { currentTheme, currentThemeName, isDark, themes, setTheme, toggleDark, registerTheme } =
  useTheme()

// Set theme
setTheme('ocean')

// Toggle dark mode
toggleDark()

// Register a custom theme at runtime
registerTheme({ name: 'custom', label: 'Custom', cssClass: 'theme-custom' })
```

See the [Theming](/theming/overview) section for complete details.
