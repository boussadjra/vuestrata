# Configuration

## Environment Variables

Copy `.env.example` to `.env.local` in the project root and customise the values:

```bash
# Build target: 'demo' (MSW, no backend) | 'production' (your API)
VUESTRATA_RUNTIME_MODE=demo

# Application title
VUESTRATA_APP_TITLE=Vuestrata

# API base URL: a same-origin path, or your API's absolute URL
VUESTRATA_API_URL=/api

# MSW mocks: must be true in demo mode and false in production mode
VUESTRATA_USE_MOCKS=true

# Auth adapter: 'mock' (demo mode only) | 'jwt' | 'oauth'
VUESTRATA_AUTH_ADAPTER=mock

# Icon Provider: 'solar' | 'lucide' | 'phosphor' | 'iconoir' | 'tabler' | 'mingcute' | 'remix' | 'griddy' | 'iconamoon'
VUESTRATA_ICON_PROVIDER=solar
```

The values are validated by `src/modules/core/lib/config/env.schema.ts` —
strictly, so an incompatible combination stops `vpr dev` or `vpr build` before
anything reaches a browser — and reach the app through
`src/modules/app/config/app.config.ts`. User-selected icon, theme, and locale
preferences are then persisted through the app store.

To run the dev server against your own API instead of MSW, see
[Develop Against Your Backend](/docs/getting-started/develop-against-your-backend).

## UI Components

The `Ui*` component layer is fixed to the repo's Reka UI implementation. There is no runtime UI-provider switch or environment key for swapping the component library.

## Icon Provider

Icons are resolved through a semantic adapter. Nine built-in icon sets are available (`solar`, `lucide`, `phosphor`, `iconoir`, `tabler`, `mingcute`, `remix`, `griddy`, `iconamoon`). Switch them through the settings page or the app store:

```ts
import { useAppStore } from '~/stores/app'

const appStore = useAppStore()

appStore.setIconProvider('lucide')
```

::alert{type="info"}
Custom icon maps can be registered at runtime via `registerIconMap(name, map)`.
::

## Validation

The template ships with Zod as the single supported schema library for forms and validation examples.

## Theme Configuration

Themes are managed via CSS custom properties and the `useTheme()` composable. Built-in themes: `default`, `analog`, `blueprint`, `brutalist`, `forest`, `ghibli`, `harbour`, `ocean`, `pro`, `rose`, `sunset`, `terminal`.

```ts
const { currentTheme, currentThemeName, isDark, themes, setTheme, toggleDark, registerTheme } =
  useTheme()

// Set theme
setTheme('ocean')

// Toggle dark mode
toggleDark()

// Register a custom theme at runtime
registerTheme({ name: 'custom', label: 'Custom', cssClass: 'theme-custom' })
```

See the [Theming](/docs/theming/overview) section for complete details.
